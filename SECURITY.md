# Security

## Reporting a vulnerability

Please report security issues privately through GitHub Security Advisories on
this repository. Do not open a public issue for a suspected secret leak.

## Secrets

- No API key, token, or password is stored in this repository.
- Provider keys live in the GitHub `research` environment as environment
  secrets. They are passed to the router only as environment variables.
- The router's own keys (`FREE_LLM_API_KEY`, `FREE_LLM_MASTER_KEY`) are
  generated by the workflow.
- Keys are never echoed in logs. Request logging is disabled and the log file
  is deleted after each run.
- If a key is suspected leaked, revoke it at the provider, rotate the matching
  GitHub secret, and re-run the research workflow.

## Data

- The site is static. It does not read user accounts, store cookies, or run
  analytics.
- The only browser storage is the theme choice under the `oar-theme` key.
- Allowances are published plan limits, not live account balances.
